# Curves-2D
Software for visualizing planar curves and their associated derived curves.

## Files

- `Curvas_2D`: executable program.
- `CurvesManual2D.pdf`: user manual in PDF format.
- `CurvesManual2D.odt`: editable version of the user manual.

## Description

The program allows the visualization of planar curves (initial curves) and other curves derived from them.

## Usage

Download the executable file and consult `CurvesManual2D.pdf` for instructions on how to use the program.
